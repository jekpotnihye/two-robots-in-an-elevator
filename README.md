# Two Robots in an Elevator

One line of awkward small talk that one robot says to another in an elevator:

`My sensors say this elevator silence is awkward. I practiced my smile for six floors. It is still loading.`

A robot whose sensors name the awkward silence, who has spent six floors practising a smile for the other robot — and the smile is still loading. The twist lands on the last two words.
